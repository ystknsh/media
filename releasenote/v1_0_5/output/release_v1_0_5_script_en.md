# 🎉 MulmoCast v1.0.5 Released!
# 🎉 MulmoCast v1.0.5 リリース！

## November 15, 2025
## 2025年11月15日

</div>

We have released MarmoCast version 1.0.5! There are five major updates in this version.

### 1. Click-to-Open File Selection Dialog for Loading Files <br> 1. クリックで開くファイル選択画面でファイルを読み込み

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat1_03.png?raw=true" alt="File Selection Dialog 1" width="80%">
</div>

First, a "file selection screen" that opens with a click can now be used for loading files. The traditional drag-and-drop method is still available.

### BEAT tab > Image or Movie file <br> BEAT タブ > 画像または動画ファイル

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat1_01.png?raw=true" alt="File Selection Dialog 2" width="80%">
</div>

You can use this when importing image or video files to the BEAT tab.

### Materials > image file <br> 素材 > 画像ファイル

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat1_02.png?raw=true" alt="File Selection Dialog 3" width="80%">
</div>

It can also be used when loading image files in the material tab.

### 2. Reuse Generated Images and Videos Across BEATs <br> 2. プロジェクト内の生成済み画像・動画を他のBEATで再利用可能

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat2_03.png?raw=true" alt="Reuse Generated Media 1" width="80%">
</div>

Second point. Images and videos generated within a project can now be reused in other beats. You can select materials that have already been generated within the project from the file selection screen.

### BEAT tab > Image or Movie file <br> BEAT タブ > 画像または動画ファイル

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat2_01.png?raw=true" alt="Reuse Generated Media 2" width="80%">
</div>

This can also be used when loading image or video files in the BEAT tab.

### Materials > image file <br> 素材 > 画像ファイル

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat2_02.png?raw=true" alt="Reuse Generated Media 3" width="80%">
</div>

You can also use it when loading image files in the materials tab.

### 3. Specify BEAT Duration in Image Generation Prompt (Advanced Mode) <br> 3. 画像生成プロンプトでBEAT時間を指定可能（上級モード）

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat3_01.png?raw=true" alt="BEAT Duration 1" width="80%">
</div>

Third, in the advanced mode "image generation prompt," you can now specify the time for each beat.

### 3. Specify BEAT Duration in Image Generation Prompt (Advanced Mode) <br> 3. 画像生成プロンプトでBEAT時間を指定可能（上級モード）

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat3_02.png?raw=true" alt="BEAT Duration 2" width="80%">
</div>

The time that can be set differs depending on whether video generation is enabled.

### 4. Character Tab Renamed to Materials Tab <br> 4. 「キャラ」タブを「素材」タブへ名称変更

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat4_01.png?raw=true" alt="Materials Tab" width="80%">
</div>

Fourth: The name of the "Character" tab has been changed to the "Materials" tab.

### 5. Preset Templates Added for Mermaid Diagrams <br> 5. Mermaid図表用のプリセットテンプレートを追加

<div align="center">
<img src="https://github.com/ystknsh/media/blob/main/releasenote/v1_0_5/images/beat5_01.png?raw=true" alt="Mermaid Templates" width="80%">
</div>

Fifth, added preset templates to Mermaid.
